# 🎥 Vidéos de restauration — Chez Gerry 1958

Ce dossier est pensé comme un **index des vidéos** liées aux projets de l’atelier.

Idées de contenu :

- fichiers Markdown listant les vidéos par :
  - modèle (ex : Red Wing 8084, 875, 3522…)  
  - type de service (ressemelage complet, Vibram, Birkenstock, etc.)  
  - thème (hiver, moto, travail, ville…)

Exemple de fichier à créer :

- `videos/red-wing-8084-upgrade.md`  
- `videos/birkenstock-conversion-vibram.md`

Chaque fichier pourra inclure :

- le lien YouTube / Instagram / TikTok  
- le type de semelle utilisée  
- le résumé du travail réalisé  
- un lien vers le dataset correspondant dans `/data/`
